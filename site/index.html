ハミングと副鼻腔の換気

ハミングで副鼻腔の空気がどれだけ入れ替わるかを、共鳴モデル・3D の流体計算（格子ボルツマン法）・鼻の NO（一酸化窒素）のモデルで調べる研究用のページです。

これは換気の物理を調べるための計算です。診断や治療の効果を示すものではありません。

換気 3D

マイクで声の高さを取り、架空の頭の中で副鼻腔の空気が入れ替わる様子をその場で見ます。上顎洞をタップすると拡大し、洞の中に新しい空気が広がる様子（事前に回した 3D 流体計算）を見られます。

スマホ・パソコン。マイクは Safari / Chrome で（アプリの中のブラウザでは使えないことがあります）

換気マップ

4 種類の副鼻腔について、音の高さごとの換気、拡散、粘膜の腫れ・粘液、倍音、鼻の NO の出方を計算します。

スマホ・パソコン

統合版（実際の上顎洞）

CT データ（NasalSeg）の上顎洞で 3D 流体計算を回し、NO のモデルにつないで文献の測定と比べます。

パソコンの Chrome / Edge（WebGPU が必要）

丸み検証

自然口の縁の丸みが換気をどう変えるかを、3D 流体計算で確かめます。

パソコンの Chrome / Edge（WebGPU が必要）

モデルの式、計算の確かめ方、分かったことと分かっていないことは、リポジトリの docs/ と results/ にあります。いちばん大きな仮定は鼻腔内の音圧（実効 180 Pa）で、これは測られた値ではなく、人の NO の測定に合わせた値です。
